# 6 Abodes Properties

Website for 6 Abodes Properties in Rochester, Minnesota.

## Free hosting with Cloudflare Pages

Connect this repository in Cloudflare Pages. Choose framework None, production branch main, leave the build command blank, and set the build output directory to `.` (repository root). No dependencies or build step are needed.

## Files

- index.html: website content and Zillow application link
- style.css: responsive design
- app.js: navigation and email draft behavior
- architecture.svg: original architectural illustration
- PDF files: blank downloadable lease templates

Owner-only lease preparation and billing tools are disabled and their HTML pages are excluded. Maintenance email: cubjewelsccc@msn.com. General inquiries: 6aprops@gmail.com. Applications are completed on Zillow. Contact messages open an email draft; they are not stored by this website.
